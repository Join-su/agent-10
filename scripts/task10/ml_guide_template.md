# 고장 예측 모델 해석 안내서

> 가상 문서(synthetic_manual) — 과제 10 학습용으로 만든 안내서입니다. 검증 수치는 학습 자료 생성 스크립트가 실제로 계산한 값입니다.

이 안내서는 MC-01의 고장 예측 모델 **{model_id}**가 만드는 이상 이벤트(EventCard)를 읽는 법을 설명합니다. 이벤트를 받은 뒤의 대응 순서는 **SOP-EA-01**, 고장 유형별 점검은 **MC01-MM** 4장을 따릅니다.

## 1. 모델 개요

### 1.1 무엇을 예측하는가

다섯 개 센서 값으로 네 가지 고장 유형(TWF·HDF·PWF·OSF)이 일어날 확률을 각각 계산합니다. 유형마다 따로 학습한 로지스틱 회귀 모델 네 개로 이루어져 있습니다.

**무작위 고장(RNF)은 예측하지 않습니다.** 센서 값과 관계없이 일어나는 고장이라 학습할 신호가 없습니다(MC01-MM 4.5).

### 1.2 입력

| 입력 | 설명 |
|---|---|
| 공기 온도, 공정 온도, 회전수, 토크, 공구 마모 시간 | 센서 값 다섯 개 |
| 온도 차 | 공정 온도 - 공기 온도 |
| 기계 출력 | 토크 × 회전수 × 2π / 60 |
| 품질 등급 | L·M·H |
| 출력 극단값 | 기계 출력이 평균에서 멀어진 정도. 출력 부족과 과다를 함께 잡기 위한 값 |
| 부하 지수 | 공구 마모 시간 × 토크 |

### 1.3 학습 기간

| 항목 | 값 |
|---|---|
| 학습 기간 | {train_from} ~ {train_to} |
| 학습 데이터 | MC-01 운전 기록 {train_rows}건 |
| 검증 데이터 | 학습 기간 중 공구 교체 주기 20%를 떼어 낸 {valid_rows}건 |
| 운영 시작 | {issued} |

## 2. 출력 필드

| 필드 | 뜻 |
|---|---|
| probabilities | 유형별 고장 확률. 네 값의 합이 1이 아닙니다. 유형마다 독립적으로 계산하기 때문입니다 |
| thresholds | 유형별 경보 기준. 하나라도 넘으면 이벤트가 만들어집니다 |
| candidates | 기준을 넘은 유형 전부. 둘 이상이면 복합 고장 의심입니다 |
| predicted_failure_type | candidates 중 확률이 기준을 가장 크게 넘은 유형 |
| confidence_level | 예측 유형의 확률이 0.8 이상이면 high, 0.5 이상이면 medium, 그 아래는 low |
| severity | confidence_level 이 high·medium 이면 alarm, low 면 warning |
| top_signals | 이 예측에 가장 크게 기여한 입력 세 개. value 는 이번 값, reference 는 학습 기간 평균 |

### 2.1 top_signals 읽는 법

contribution 이 클수록 그 입력이 예측을 밀어 올린 정도가 큽니다. 다만 top_signals 는 **모델이 무엇을 보고 판단했는지**를 보여 줄 뿐, 그것이 고장의 원인이라는 뜻은 아닙니다. 원인은 매뉴얼 판정 기준과 점검으로 확인합니다.

예를 들어 HDF 예측의 top_signals 에 온도 차와 회전수가 함께 있으면 매뉴얼 4.2.2 의 두 조건과 같은 방향입니다. 공기 온도만 높게 나와 있으면 외부 기온 때문일 수 있으므로 판정 기준으로 다시 확인합니다.

## 4. 알려진 약점

### 4.1 공구 마모 고장(TWF)을 잘 예측하지 못한다

공구 마모 고장은 마모 시간이 200 ~ 240분인 구간에서 갑자기 일어납니다. 같은 마모 시간이라도 고장이 나는 경우와 나지 않는 경우의 센서 값 차이가 거의 없어 확률이 낮게 나옵니다. 그래서 TWF 만 경보 기준을 0.10 으로 낮췄습니다. 그 결과 **TWF 이벤트는 대부분 low 확신도의 warning 이고 오탐이 많습니다.**

TWF 이벤트는 확률이 아니라 공구 마모 시간과 마지막 공구 교체 기록으로 판단합니다(MC01-MM 4.1.3, SOP-EA-01 4장).

### 4.2 경계 근처에서 흔들린다

매뉴얼 판정 기준의 경계(온도 차 8.6 K, 회전수 1,380 rpm, 출력 3,500 W·9,000 W, 부하 지수 한계) 근처에서는 확률이 0.4 ~ 0.6 사이로 나오기 쉽습니다. 이 구간의 예측은 판정 기준으로 반드시 다시 확인합니다.

### 4.3 외부 기온의 영향을 받는다

공기 온도가 높은 기간에는 온도 차가 작아져 HDF 확률이 올라갑니다. 회전수가 높은데 HDF 가 예측됐다면 오탐 가능성을 먼저 봅니다.

### 4.4 고장을 놓칠 수 있다

경보가 없다고 고장이 없는 것은 아닙니다. 무작위 고장과 경보 기준 아래의 고장은 이벤트로 오지 않습니다. 운전자 보고로 발견된 고장은 정비 이력에 trigger: operator_report 로 남습니다.

## 5. 사용 원칙

1. 확률은 확정이 아닙니다. 모든 이벤트는 매뉴얼 판정 기준으로 다시 확인합니다.
2. 예측 유형과 판정 기준이 다르면 SOP-EA-01 6장의 escalation 기준을 따릅니다.
3. 같은 조건에서 오탐이 반복되면 정비 이력의 false_alarm_check 기록과 함께 모델 담당에게 알립니다.
4. 모델을 다시 학습하면 이 안내서의 검증 결과와 개정 번호를 함께 바꿉니다.
